# R55: slug 字段空白字符串 + 前后空格校验（R37/R53 同型遗漏，与 Category.id 对齐）

**轮次**: R55
**日期**: 2026-07-24
**主题**: Horizontal 审计发现 slug 字段缺少空白字符串和前后空格校验，与 Category.id（R37/R53 已覆盖）不一致
**状态**: 已完成
**相关模式**: R37, R53, R31

## 背景

R37 给 name/description（free-text 必填字段）加了空白字符串校验，R53 给所有 free-text 字段（包括 Category.id）加了前后空格校验。

slug 是与 Category.id 同型的字段（URL-friendly 格式，用于路由），但遗漏了空白字符串和前后空格校验。

## Gap 发现

### Horizontal 审计：slug vs Category.id

| 字段 | 空白字符串校验 | 前后空格校验 | URL-friendly 校验 | 唯一性校验 |
|------|---------------|-------------|------------------|-----------|
| Category.id | ✓ (R37) | ✓ (R53) | ✓（有 trim 防御） | ✓ |
| slug | **✗** | **✗** | ✓（无 trim 防御） | ✓ |

**Gap**: slug 缺少空白字符串和前后空格校验，与 Category.id 同型不一致。

## 攻击向量验证

### 纯空白字符串

```yaml
slug: "   "
```

修复前报错：
- slug "   " 与文件名 "xxx" 不一致
- slug "   " 不是 URL-friendly 格式

**问题**：两个错误都是误导性的——真实问题是"空白字符串"而非"不一致"或"格式错误"（R31 模式违反）。

### 前后空格

```yaml
slug: " astro "
```

修复前报错：
- slug " astro " 与文件名 "xxx" 不一致
- slug " astro " 不是 URL-friendly 格式

**问题**：两个错误都是误导性的——真实问题是"前后空格"而非"不一致"或"格式错误"（R31 模式违反）。

## 影响分析

| 维度 | 影响 | 严重度 |
|------|------|--------|
| 数据质量 | slug 含前后空格或纯空白，数据不干净 | MINOR |
| 贡献者体验 | 错误信息误导，贡献者不知道应该 trim 空格 | MINOR |
| 同型一致性 | Category.id 有空白+前后空格校验，slug 没有，模式不一致 | MINOR |

## 修复方案

在 slug 校验链中增加：

1. **空白字符串校验**（`p.slug.trim() === ''`）—— 在所有校验之前
2. **前后空格校验**（`p.slug !== p.slug.trim()`）—— 在空白字符串之后、文件名一致性之前
3. **文件名一致性校验防御性条件**——加 `p.slug === p.slug.trim()` 条件，有空格时跳过
4. **URL-friendly 校验防御性条件**——加 `p.slug === p.slug.trim()` 条件，有空格时跳过

校验顺序：
1. 空白字符串校验 → fail
2. 前后空格校验 → fail
3. 文件名一致性 → fail（仅当无前后空格时）
4. URL-friendly 格式 → fail（仅当无前后空格时）
5. 唯一性校验 → fail

## 验证

### 攻击样本验证

- 修复后报错：`slug 为空白字符串` + `slug "   " 含前导/尾部空格`

## 模式确立

### 同型字段对齐模式（再次确认）

同用途、同格式的字段（如 slug 和 Category.id，都是 URL-friendly 路由标识符）必须有相同深度的校验。

### R31 模式扩展（文件名一致性）

不仅格式/枚举校验需要在空格字段上跳过，文件名一致性校验也需要——含前后空格的 slug 与文件名必然不同，但"前后空格"是比"不一致"更基础的错误，应该优先报告。

## 同型对齐完整矩阵

| 字段类型 | 空字符串 | 纯空白 | 前后空格 | 中间空格 | 格式/内容校验（带 trim 防御） |
|---------|---------|--------|---------|---------|----------------------------|
| free-text 必填 (name/desc) | 隐式 | ✓ (R37) | ✓ (R53) | - | - |
| free-text 可选 (lic/lang) | ✓ | ✓ (R37) | ✓ (R53) | - | ✓ (SPDX，带 trim 防御 R53) |
| URL 格式 (url) | ✓ | ✓ (R52) | ✓ (R52) | - | ✓ (URL + 协议白名单) |
| repo 格式 | ✓ | ✓ (R37 隐式) | ✓ (R37) | ✓ (R40) | ✓ (split 格式 + 空段 R51) |
| URL-friendly id (slug/category.id) | ✓ | ✓ (R37+R55) | ✓ (R53+R55) | - | ✓ (urlFriendlyRe，带 trim 防御 R53+R55) |
| 数组元素 (tags/sources) | ✓ (R35) | ✓ (R39) | ✓ (R54) | - | ✓ (枚举，带 continue 防御 R54) |
